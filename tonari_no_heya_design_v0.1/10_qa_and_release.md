# 10. QA・公開準備

## 機能テスト

- [ ] 新規開始→1日目終了まで停止しない。
- [ ] 郵便を取らず203扉へ行っても誘導がある。
- [ ] 手紙・ベランダの任意演出を見逃してもクリアできる。
- [ ] 書類を何度も開閉しても入力がロックされない。
- [ ] 202扉は開かず、隣室内部が見えない。
- [ ] 1日目のノックの返答回数が正しい。
- [ ] 2日目の照明が止まっても重要箇所を調べられる。
- [ ] 電話ヒントを聞き逃しても3日目に進める。
- [ ] 点検口の工具・図面で詰まない。
- [ ] エンディングで足音や怪異の姿を追加していない。
- [ ] セーブ・ロードでイベント二重再生や状態破損がない。

## 演出テスト

- [ ] ノックが怖いが不快な大音量ではない。
- [ ] 1日目は生活感、2日目は停電、3日目は微細な違和感が伝わる。
- [ ] ベランダの黒い部分が人影と断定できない。
- [ ] 管理会社の異常音声が物語の真相を明言しない。
- [ ] 最後の呼吸停止は、急激な効果音で説明しない。
- [ ] 郵便受けの構図が冒頭と対応する。

## ユーザビリティテスト

- [ ] 文字が低解像度効果に潰されない。
- [ ] FOV・マウス感度・字幕サイズを調整できる。
- [ ] 暗さで進行不能にならない。
- [ ] 必須の音情報に字幕または視覚補助がある。
- [ ] プレイヤーが今何をしたいか、最低限理解できる。
- [ ] 操作不能の場面が意図的な演出と分かる。

## Steam公開準備（公開直前に最新要件を再確認）

- [ ] Steamworksアカウント・アプリ登録・費用・公開条件を公式情報で確認。
- [ ] ストアページ、短い説明文、スクリーンショット、カプセル画像、トレーラーの要否を確認。
- [ ] 対応OS・最低動作環境・言語・字幕・操作方法を記載。
- [ ] ゲーム内外のアセット・フォント・効果音・素材の商用利用・再配布権を確認。
- [ ] Godotのライセンス表示要件を確認。
- [ ] リリース用ビルドでデバッグUI・テストコマンドを無効化。
- [ ] 別PCで起動・クリア・終了・設定保存を確認。
- [ ] 重大な点滅・音量・ホラー表現に必要な注意書きを検討。

**注**：Steamの費用・審査期間・規約は変更され得るため、本設計書には未検証の具体値を書かない。
