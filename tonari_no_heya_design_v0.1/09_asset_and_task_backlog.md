## マイルストーン

### M0：歩ける空間

- [ ] Godot 4プロジェクト作成、Git初期化、`.gitignore`設定
- [ ] 203・廊下・ベランダの仮モデル配置
- [ ] 一人称移動、衝突、ドアの行き来
- [ ] 基本照明と音量設定

**完了条件**：最初の場所から203へ入り、ベランダまで歩ける。壁抜けしない。

### M1：調査できる空間

- [ ] Eで調べる、表示距離・プロンプト
- [ ] 郵便物回収と机に置く処理
- [ ] 書類ビュー、戻る、メモ
- [ ] 202扉の無応答イベント

**完了条件**：郵便物を回収し、手紙を読み、202扉を確認できる。

### M2：1日目プレイアブル

- [ ] 壁のノックと主人公の反応
- [ ] 契約書と管理会社の連絡先
- [ ] ベランダの任意異変
- [ ] 夜間の連絡→就寝→叩き返し→応答
- [ ] テストプレイ、詰み修正

**完了条件**：初見プレイヤーが10〜15分で1日目を完走できる。

### M3：2日目

- [ ] 停電・スマホライト
- [ ] 202郵便受け・追加調査
- [ ] 管理会社の電話イベント、音声代替ヒント

### M4：3日目・結末

- [ ] 棚の差分・図面・点検口

### M5：公開準備

- [ ] クレジット・権利確認
- [ ] Steam用素材・説明・ビルド・ストア準備

## タスクの粒度

1タスクは原則**半日〜2日で検証可能**な単位に分割する。例：「廊下を作る」ではなく「郵便受けから203扉まで移動し、Eで両方を操作できる」。

## 最初の3タスク

1. `Player`シーンを作り、WASD＋マウス視点＋衝突を実装。
2. `ApartmentFloor`に203室内・廊下・ベランダのグレーボックスを置く。
3. `Interactable`と`InteractionRay`を実装し、郵便受けをEで調べられるようにする。
