# 02. レベル・間取り設計

## 空間の考え方

**203号室を唯一の詳細な生活空間**にする。共用廊下と203のベランダを接続し、202号室は扉・郵便受け・ベランダ側の窓のみ外観を用意。内部は作らない。

## 初期グレーボックス配置（提案・未確定）

```text
                    共用廊下（2階）
   [201扉]      [202扉]       [203扉]        [205扉]
                 │              │
                 │         ┌────┴──────────┐
                 │         │ 玄関・靴置き  │
                 │         │   廊下         │
                 │         │               │
                 │         │ 机／書類棚    │
                 │         │               │
                 │         │ ベッド   棚   │
                 │         │         [点検口] ←202側の共有壁
                 │         ├────窓──────────┤
                 │         │ 203ベランダ   │
                 └─────── 202側のベランダは外観のみ
```

**重要**：これは制作しやすい**仮配置**。図の201・202・203・205という並びは、契約書に202が載らない設定とまだ整合確認が必要。図面の最終決定時には廊下側とベランダ側で202と203が確実に隣接するよう、3D座標で検証する。奇数号室の間に202がある理由を超常現象として確定しない。

## グレーボックス寸法（Godot 1単位≒1m、仮）

| 領域 | 仮寸法 | 注意 |
|---|---|---|
| 203室内 | 幅4.2m×奥行6.0m | 一人称で歩きやすい余白を優先 |
| 天井高 | 2.4m | 圧迫感は画角・照明で調整 |
| 玄関から居室 | 幅0.95m | 立ち止まり・振り返り可能 |
| 共用廊下 | 幅1.6m | 郵便受けと扉の前に立てる |
| ベランダ | 奥行1.1m | 202側を覗けるが越境不可 |
| 点検口 | 幅0.35m×高さ0.25m | 棚を動かすまで見えない |

## 203号室の固定オブジェクト

- **玄関扉**：出入り、廊下への切替点。
- **照明スイッチ**：1日目は点灯、2・3日目は反応音のみ。
- **机**：郵便物を広げる、書類ビューの起点。
- **引き出し・書類棚**：契約書・管理会社連絡先。
- **共有壁**：ノックの主な音源、3日目の点検口。
- **小さな棚**：3日目にわずかに位置が変わる。
- **ベッド**：日付進行と最終イベントのトリガー。
- **窓・カーテン**：ベランダへの移動、外光。
- **雑貨**：マグカップ、服、箱、時計など。触れるものは絞る。

## 共用廊下の固定オブジェクト

- 203郵便受け（冒頭で回収、最後は回収されない）
- 202扉（ノック可・開けられない）
- 202郵便受け（2日目に確認）
- 203扉、共用蛍光灯、階段の一部（階段は進行不可でもよい）

## 視線・怖さの設計

- 玄関から部屋全体を一度に見通せないよう棚で遮る。
- ベッドから共有壁と棚の下部は視認しにくくする。
- ベランダから202の窓は見えるが室内は見えない。
- 廊下の固定カメラは**冒頭とエピローグで同一構図**を使う。

## 制作上の決定待ち

建物全体の号室配置、室内水回りの省略可否、点検口が建築的にどの設備へ通じるか（配管スペースで十分）、ベランダの隔て板の位置。**設備上の説明と怪異の正体は別問題**として扱う。
