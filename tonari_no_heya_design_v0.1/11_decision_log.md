# 11. 決定事項・未決事項・変更履歴

## 決定済み（作品方針）

| ID | 内容 | 理由 |
|---|---|---|
| DEC-001 | PS1風ローポリ3D一人称 | ざらついた現実感と低コスト制作 |
| DEC-002 | 3日間、45〜60分程度 | 同じ空間の変化を見せる |
| DEC-003 | 203号室を中心に、202内部は作らない | 見えない隣室の怖さ |
| DEC-004 | 戦闘・追跡・ジャンプスケアを中心にしない | 静かな心理ホラー |
| DEC-005 | 点検口を開けたことが死の原因とは限らない | 理不尽な死と不条理 |
| DEC-006 | 主人公は最後に眠ろうとする | 生活の動機の一貫性 |
| DEC-007 | 呼吸が途絶える→無人の郵便受け→ノック | C＋Bの統合エンディング |
| DEC-008 | エピローグに新入居者の足音なし | 説明を増やさない |
| DEC-009 | 謎解きの手がかりは公平に提示 | 理不尽なのは物語、操作ではない |

## M0実装上の仮決定（実装に合わせて更新）

| ID | 内容 | 状態・見直し条件 |
|---|---|---|
| M0-001 | 描画方式は既存の `project.godot` に合わせてCompatibilityを使う | 設定で確認済み。Forward+へ変更する場合は実機性能と必要な描画機能を確認してから決める |
| M0-002 | 初期グレーボックスは203号室を幅4.2m×奥行6.0m、天井高2.4mとする | 既存の寸法案を仮採用。GUIでの歩行・視線確認後に調整する |
| M0-003 | 202扉・203の共有壁・202ベランダ外観を203の左側に揃え、203への出入り、机・ベッド・共有壁への移動、ベランダへのアクセスを確保する | 自動歩行で廊下とベランダの往復を確認済み。号室配置の物語的な理由は確定しない |
| M0-004 | 202号室は扉・郵便受け・外から見える窓などの外観だけとし、内部シーンを作らない | 作品方針DEC-003に従う |
| M0-005 | 初期グレーボックスはGodot標準のプリミティブ形状・標準機能で組み、外部アセットや画質効果を前提にしない | 操作と空間寸法の確認後に必要な素材を選ぶ |
| M0-006 | M0ではノックなどの演出音を実装せず、Godot標準のMasterバスを使う | 演出音と追加バスはM1以降で必要に応じて設計する |
| M0-007 | 203入口とベランダ入口は固定の開口とし、M0では扉の開閉処理を作らない | M0の目的は移動導線の検証。インタラクションはM1の範囲 |
| M0-008 | プレイヤーは共用廊下の203入口前から、室内方向を向いて開始する | 廊下→203→ベランダの導線をすぐ確認できるようにする |

Compatibility / Forward+ の選択はプロジェクト設定との整合が必要なため、実装前に `project.godot` を確認する。ここでは現在設定済みのCompatibilityを記録し、別方式への変更を既定にしない。

## 意図的に未決定のまま残すこと

- 怪異の正体、202号室の真相、管理会社の声の正体。
- 主人公の医学的な死因、死の回避可能性、点検口との因果。

これらは「後で真相を決めるための未決」ではなく、**作品の余韻を守るために説明しない項目**。
