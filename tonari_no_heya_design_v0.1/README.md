# 『となりの部屋』ゲーム設計パッケージ v0.1

**対象**：Godot 4.x / PC（Steam無料公開を想定） / 一人称3D・短編心理ホラー / 45〜60分。  
**制作方針**：まず1日目の10〜15分を完成させ、怖さ・操作性・制作工数を検証する。  
**原作**：`00_reference/scenario_v0.3.md`。この設計パッケージは実装用の具体化案であり、原作の意図を変更するものではない。

## 最初に読む順番

`01` → `02` → `03` → `04` → `08` → `09`。イベントやパズルを実装する際に`05`・`06`を参照する。

## 設計の確度

- **確定方針**：3夜、203号室、202号室の内部なし、戦闘・追跡なし、C＋B統合エンディング、最後に足音なし、怪異と死因を説明しない。
- **実装上の提案**：寸法、配置、入力キー、ノード名、状態名、各イベントの正確なタイミング。
- **未決**：202号室と書類の不一致の最終設定、管理会社への連絡方式、3日目の謎解きの確定台本、点検口の内部物、郵便受けの封筒。
