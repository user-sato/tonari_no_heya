# 07. ビジュアル・音響・演出ガイド

## 画面の方向性

- **PS1風の粗い3D**：低ポリゴン、低解像度レンダリング、控えめなディザリング・フィルム粒子。
- 夜の青・紫を基調に、室内の暖色灯を対比。1日目はまだ生活感がある。
- UIの文字まで荒くしない。書類本文・字幕は常に読める。
- 画面ノイズは怖さを補助するだけ。激しいフラッシュ、過度な揺れは禁止。

## 3夜のライティング

| 夜 | 主光源 | 見え方 |
|---|---|---|
| 1日目 | 室内照明＋外の街灯 | 安心できる室内、暗い窓の向こう |
| 2日目 | 街灯・月光・スマホライト | 電気停止は現実のトラブル。家具の輪郭は見える |
| 3日目 | 2日目と同じ | 見慣れた暗さの中で、棚の位置が違う |
| エピローグ | 共用廊下の蛍光灯 | 冒頭とほぼ同じ画角、主人公だけ不在 |

## 音のレイヤー

- **環境音**：遠い車、風、廊下の蛍光灯、布擦れ、足音。
- **生活音**：鍵、郵便受け、紙、スイッチ、引き出し、ベッド。
- **ノック**：小さく乾いた音。初期は隣から、終盤は距離感が揺らぐ。
- **異常音**：2日目の通話で声が低く、こもり、断片的になる。急激な爆音なし。
- **無音**：終盤で意図的に長く取る。音を止めること自体を演出にする。

## 具体的な音響イベント

| ID | 内容 | 実装上の注意 |
|---|---|---|
| `sfx_knock_wall` | 共有壁のノック | AudioStreamPlayer3D、距離減衰は過度にしない |
| `sfx_knock_reply` | 叩き返した回数と同じ返答 | タイミングにわずかな間を置く |
| `sfx_phone_normal` | 管理会社の普通の声 | 聞き取れる帯域 |
| `sfx_phone_distorted` | 声の低下・こもり | 断片を強調しすぎない、字幕代替あり |
| `sfx_scrape` | 2日目の家具を引くような音 | 発生位置は明確に断定させない |
| `sfx_final_breath` | 3日目の呼吸 | 徐々に間隔が伸び、次が来ない |
| `sfx_final_knock` | エピローグのノック | 小さく、音源不明 |

## カメラ演出

- 通常はプレイヤー操作を尊重し、怪異を見せるための強制視点移動を避ける。
- 3日目の最後だけ、ベッドに横になって天井を見る固定視点へ移行。
- 何かが近づく姿・影・襲撃モーションは出さない。
- エピローグは冒頭と同じ共用廊下の固定構図。足音は入れない。

## 低コストな表現方法

- 生活小物は低ポリの単色・粗いテクスチャで統一。
- カーテンの違和感はメッシュの差分・ライトの差分で表現。
- 家具の移動は数cm〜十数cmの差分。動く瞬間は見せない。
- 202室内は暗い窓面と遮蔽物のみで成立させる。
